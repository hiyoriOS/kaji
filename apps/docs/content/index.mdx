Kaji is a TypeScript library for running application actions, like `refundPayment()` or `cancelBooking()`, when an agent, automation, or API caller asks for them. It validates input, checks permission, asks for approval when needed, runs the action once per request, and reports what happened.

2. [Capabilities](/docs/concepts/capability): define an action and its rules.
3. [Outcomes](/docs/concepts/outcomes): what each result means and what to do with it.
4. [Stores](/docs/concepts/stores): where Kaji keeps its records.
5. [Idempotency](/docs/concepts/idempotency): make retries safe.
6. [Cancellation](/docs/concepts/cancellation): abort requests and set timeouts.

8. [Troubleshooting](/docs/troubleshooting): fix common errors and unexpected results.
